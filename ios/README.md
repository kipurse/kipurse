# Kipurse iOS

The iPhone app and its Swift package. The app is the wallet owner's control panel: it sets limits, approves payments above them with Face ID,
shows the on-chain record and moves money out. Payments themselves run on Base mainnet through the Kipurse contracts (V5.5); the app checks
every batch it is asked to sign on the phone before any signing page opens.

## Layout

| Path | What |
|---|---|
| `Sources/KipurseCore` | Swift package (Foundation only): request verification (`RequestVerify`, `BatchVerify`), limits and fee rules shared with the gateway, phone trust / key seat helpers, owner API client, localization. Runs on macOS and Linux. |
| `Tests/KipurseCoreTests` | Unit tests for the package, including cross-check vectors generated by the gateway. |
| `App` | SwiftUI app (iOS 17+): onboarding, limits, approvals, record, withdraw, connect AI, emergency stop. `App/Assistant` is the optional Siri / Spotlight module. |
| `Widget` | Home-screen widget. |
| `UITests` | XCUITest suite (runs against local mocks). |
| `project.yml` | XcodeGen project; `Config/Kipurse.xcconfig` + `Config/Local.xcconfig.example` hold build settings. |

## Build and test

```sh
# Swift package (no Xcode project needed)
cd ios && swift test

# App: generate the Xcode project, then build or test
brew install xcodegen
cd ios && cp Config/Local.xcconfig.example Config/Local.xcconfig   # set your own team / bundle prefix
xcodegen generate
xcodebuild -project Kipurse.xcodeproj -scheme Kipurse -destination 'platform=iOS Simulator,name=iPhone 16' test
```

## Release build notes

- Release builds accept only `https://` servers; plain-HTTP local-network servers and the local-network permission exist in Debug builds only.
- Release push entitlement is `production`; Debug is `development`.
- The auth error log (`kp-auth.log`, no secrets) lives in Application Support, not in Documents.
- The app has the hosted service's signing / API hosts and fee address built in (`SignHost.swift`, `OwnerExit.swift`, `RequestVerify.swift`,
  `UsdcGas.swift`). A self-hosted fork must change them and ship its own build.
