# 启付费用（公开透明，全部以 USDC 计）
每一笔费用都以 USDC 从你的启付钱包余额中扣除。不会扣你的银行卡，也不会由其他人代付。

| 项目 | 金额 | 何时收取 |
|---|---|---|
| 启付服务费 | 链上费用合约中的 `feePpm`（以 % 显示），向上取整到 0.000001 USDC | 每笔 AI 付款 |
| 链上网络费 | 实际 gas 成本折算成 USDC，加价 0%（`PRINCIPLES.gasMarginBps = 0`） | 每笔链上交易 |
| 提现 / 暂停 | 只收实际网络费 | 你操作时 |

每次批准前，网关都会生成一张收据（`server/src/v5/receipt.mjs`）：付给商家的金额、服务费、网络费，以及从钱包余额扣除的总额；iOS App 会在 Face ID 之前的批准页面上显示费用（`ios/Sources/KipurseCore/RequestVerify.swift`）。
调整费用需要主人决定，并在链上费用合约里写入新值；任何改动在链上都公开可查。
